# Report di collaudo

## Controlli automatici eseguiti

- validità sintattica dei file JSON;
- presenza dei file obbligatori PWA;
- presenza di manifest, icone e Service Worker;
- verifica dei riferimenti locali principali;
- avvio tramite server HTTP locale.

## Controlli manuali da completare dopo la pubblicazione

- audit Lighthouse nel dominio GitHub Pages definitivo;
- installazione reale su iPad/iPhone, Android e desktop;
- test VoiceOver/NVDA;
- verifica offline dopo il primo caricamento.

Non vengono dichiarati punteggi Lighthouse non misurati.
