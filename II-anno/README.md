# Manuale Vivo — Storia II

PWA didattica statica, installabile e utilizzabile offline, costruita dalle dispense di Storia II di gbprof e Libera.

## Contenuti

- 4 percorsi cronologici
- 48 lezioni
- problema guida, racconto storico, schema, mappa concettuale, sintesi, vocabolario e saperi irrinunciabili
- quiz a tre alternative e recupero degli errori
- evidenziazioni, note, ricerca, progresso e tempo di studio

## Pubblicazione

La cartella `II-anno` può essere servita direttamente da GitHub Pages. Tutti i collegamenti sono relativi e la navigazione usa URL con hash, quindi non richiede configurazioni del server.

## Aggiungere contenuti

I contenuti sono separati dall'interfaccia nel file `data/manuale.json`. Il codice della PWA non contiene il testo delle lezioni.

## Dati dello studente

Appunti, evidenziazioni, quiz e progresso restano nel browser mediante IndexedDB. Possono essere esportati dalla sezione Appunti.
